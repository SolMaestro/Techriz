# TechRiz Academy (V1)
1. Install Node.js (v18+). 2. In this folder run: `npm start`  3. Open http://localhost:3000

## Add your content: edit data/quizzes.json
- youtubeId: the part after v= in the YouTube link
- answer: index of the correct option (0 = A, 1 = B, 2 = C, 3 = D). Any number of questions/options per quiz.
Results are saved in data/results.json.
